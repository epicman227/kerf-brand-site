# Logos

Four files. Use the gradient mark on dark grounds, the mono mark anywhere a single color is required (favicons, print, embroidery, stamps). The wordmark lockups set "kerf" in Sora 700; in code, inline the mark and render the word as live text so the font loads. Clear space equals the outer ring thickness. Minimum mark 24px. Never place the mark on kerf green or on the gradient, never close the cut.
